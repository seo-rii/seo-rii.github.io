02

만든 것

여러 프로그램을 만듭니다. 알고리즘 문제 해결용 코드부터 웹사이트까지 가리지 않고 만듭니다.

Jungol

한글과컴퓨터학원에서 운영하는 온라인 저지를 리뉴얼했습니다.

  • 채점기를 포함한 모든 서비스를 재개발했습니다.
  • 프론트엔드는 스벨트를 사용한 MPA입니다.
  • 웹어셈블리 기반으로 작성한 소스 코드 실행을 서버 없이 지원합니다. GCC와 ld의 웹어셈블리를 이용하여 컴파일도 프론트엔드에서 수행합니다. 파이썬 실행은 Pyodide를 이용합니다.
  • LSP 서버를 구현해 웹에서 인텔리센스를 사용하여 코딩할 수 있습니다.
  • 백엔드는 Node.js와 TypeScript를 사용하여 제작했습니다. Hono 프레임워크를 사용했으며, 더욱 쉬운 MSA 개발을 위해 이를 래핑하는 프레임워크를 만들었습니다.
  • TanStack Query와 유사한 자체 쿼리 프레임워크를 구현했습니다. E2E type safety를 지원하며, 간단한 설정으로 SSR에서 로딩할 데이터를 설정할 수도 있습니다.
  • MSA 구조를 채용했으며, 메시지 큐를 이용하여 무거운 작업을 비동기적으로 처리합니다.
  • 배포 도구 역시 자체 개발했습니다. GitHub에 푸시하면 자동으로 베타 서버에 배포되며, 버튼 클릭으로 이를 프로덕션 서버에 배포할 수 있도록 자동화했습니다.
  • 문제 채점기는 직접 구현했습니다. 이 채점기에서 일부 기능이 빠진 버전이 HANA라는 이름으로 오픈소스로 공개되어 있습니다.
  • 서비스는 구글 클라우드 플랫폼에서 이루어지며, Compute Engine 같은 단순한 기능만이 아닌 Pub/Sub, Arc, GKE와 같은 기능을 적극적으로 활용했습니다.
  • Terraform으로 인프라를 관리합니다.
  • Sentry를 사용하여 오류 로그를 자동으로 수집하여 대응하고 있습니다.

codepass

Jungol의 B2B 버전입니다.

현재 삼성전자 DS 부서(해외 포함), 삼성디스플레이, SEMES, STECO와 같은 회사에서 알고리즘 교육용으로 사용되고 있습니다.

kaporido

2023년 카이스트-포스텍 학생대제전 인공지능 부문 게임인 Puoribor의 GUI 구현체입니다.

SDK는 여기 있습니다. 파이썬에서 환경과 상호작용할 수 있도록 만들어졌으며, C++으로 작성되어 빠르게 상호작용할 수 있습니다.

TTL

카이스트 시간표 작성 웹사이트입니다.

학사시스템에서 자동으로 시간표를 크롤링하여 업데이트합니다.

수강신청 주간에 평균 약 2,000명의 유저(WAU)가 사용합니다.

최대 동시 접속자(30분간 세션) 1,400명을 기록했습니다.

Ringle AI Tutor

링글의 AI Tutor 기능을 개발했습니다.

  • 리액트/리액트 네이티브/Ruby on Rails를 사용했습니다.
  • 스트리밍 처리/오디오 처리와 관련한 기술을 다뤘습니다.

AI 평가 시스템을 개선했습니다.

  • 파이썬 코드를 최적화해 속도를 약 5배 정도 향상시켰습니다. 이를 통해 실시간 음성 진단 기능을 구현했습니다.
  • 처리 파이프라인/k8s 배포와 같은 인프라 부분도 작업했습니다.

PLAT

메타버스 커뮤니티입니다. 여기우리(현 The Dimension Company)에서 초기에 개발했던 제품입니다.

  • Three.js 기반의 메타버스 커뮤니티입니다. 3차원 객체 배치 및 연산을 위한 헬퍼 라이브러리를 자체 개발했습니다.
  • WebRTC를 사용하여 화상 통화를 구현했습니다.
  • 메시지 큐를 사용하여 수평 확장 가능한 WS 시스템을 구현했습니다.
  • 스벨트 기반의 플러그인 시스템을 구현했습니다.

HyperCLOVA X

네이버의 LLM인 하이퍼클로바에 사용될 텍스트 학습 데이터를 전처리했습니다.

150 GB 이상, 1천만 개 이상의 텍스트 파일을 처리해 제공했습니다.
